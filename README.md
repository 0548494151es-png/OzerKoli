# עוזר קולי

אפליקציית אנדרואיד בעברית: חיוג עם אישור, תזכורות, טיימר, שעון מעורר, יומן, תזכורות לפי מקום,
ספירה לאחור לפני הדלקת נרות, מצב מורה ובדיקת תקלות. אין האזנה מתמדת: האפליקציה פועלת בלחיצה בלבד,
וכל התזמונים מנוהלים על ידי המערכת, לכן צריכת הסוללה זניחה.

## בנייה בלי Android Studio
1. צור ריפו חדש ב-GitHub והעלה אליו את כל תוכן התיקייה הזו (כולל `.github`).
2. בלשונית **Actions** המתן לסיום ריצת "Build APK" (כ-4-6 דקות), או הפעל אותה ידנית עם "Run workflow".
3. היכנס לריצה, הורד את **OzerKoli-apk** מהחלק "Artifacts", חלץ והתקן `app-debug.apk` בטלפון
   (יש לאפשר התקנה ממקור לא ידוע).

## הפעלה ראשונה
- אשר הרשאות כשמתבקש (מיקרופון, אנשי קשר, התראות).
- הורד חבילת עברית לזיהוי דיבור אופליין: הגדרות Google > זיהוי דיבור > שפות > עברית.
- מסך **הגדרות** מציג בדיקת תקלות עם כפתור "תקן" ליד כל בעיה.
- כעוזר דיגיטלי: הגדרות > אפליקציות ברירת מחדל > עוזר דיגיטלי, ואז לחיצה ארוכה על כפתור ההפעלה.

## דוגמאות פקודות
- תתקשר לאמא (מציג את השם, ומחייג רק כשאתה לוחץ עליו)
- תשלח הודעה לדני שאני מגיע / תשלח וואטסאפ לדני (נפתח מוכן, ואתה לוחץ שליחה)
- טיימר 10 דקות / תעיר אותי מחר ב-6:30
- תזכיר לי מחר ב-8 לקנות חלב / תזכיר לי בעוד שעה להתקשר לרופא
- תוסיף ליומן פגישה ביום שלישי ב-10:30 / מה יש לי מחר
- תזכיר לי לקנות חלב כשאגיע לסופר (גם: כשאגיע לסופר תזכיר לי לקנות חלב). אם המקום לא שמור, תוצע שמירה של המיקום הנוכחי או חיפוש לפי שם
- הדלקת נרות ב-17:32 / כמה זמן עד שבת
